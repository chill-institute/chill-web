# About chill.institute

[chill.institute](https://chill.institute) is an independently maintained
companion for searching releases, browsing movies and TV shows, and sending a
selection to your put.io account, with RSS shortcuts and a
[Stremio add-on](https://chill.institute/stremio). It is not affiliated with
put.io or the other services it connects to.

## Privacy

- The browser stores an auth token and a few interface preferences. Account
  settings live in put.io's configuration storage.
- Product analytics runs in the API with pseudonymous IDs. It excludes
  searches, media IDs, URLs, account IDs, IP addresses, user agents, and
  free-form errors.
- Crash reporting, when configured, may send the route path, runtime, release,
  and stack, never tokens, cookies, request bodies, user IDs, request URLs, or
  query strings. Without it, a crash report stays local until you copy it.
- The Stremio add-on link is a credential: anyone with it can play your put.io
  library and download to it. Stremio keeps it on the device and in your
  Stremio account; our error reports redact it. Signing out does not stop it:
  **disconnect Stremio** at [chill.institute/stremio](https://chill.institute/stremio)
  or remove chill.institute's access in put.io to stop every link within a minute.

## Help

- **Stremio:** get a link at [chill.institute/stremio](https://chill.institute/stremio)
  and select **install chill**. Tested in Stremio Web and Stremio for Linux;
  other Stremio apps are unverified.
- **Browsers:** current evergreen browsers on desktop and mobile.
- **Transfers:** put.io controls transfer health. Try another release or
  indexer, and report failures that repeat across results.
- **Bugs:** use the
  [bug report form](https://github.com/chill-institute/chill-web/issues/new?template=bug_report.yml)
  with your browser and device. For search, add the title, episode, filters,
  and sort; for crashes, the Sentry event ID or copied crash report.
- **Security or privacy problems:** use the [private route](../SECURITY.md).
